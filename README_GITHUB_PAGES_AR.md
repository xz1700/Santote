# Birthday santotye — GitHub Pages

## التشغيل محليًا
افتح `index.html` الموجود في جذر المستودع. سيحوّلك تلقائيًا إلى:

`06_birthday_new/index.html`

## النشر على GitHub Pages
1. ارفع **محتويات هذا المجلد** إلى جذر المستودع، وليس المجلد نفسه داخل مجلد إضافي.
2. من GitHub افتح: **Settings → Pages**.
3. اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
5. افتح رابط GitHub Pages؛ سيبدأ الموقع تلقائيًا من `06_birthday_new/index.html`.
